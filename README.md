# LocalStationCalcJava
MEAP II Barometric Local Station Data Calculator

This is a tool to help with the calculation of local station data in the MAEP II course at Michigan Technological University.

This tool is not designed to do anything more than calculate the local station data.
Additionally, I made this tool to make a repetitive task easier. If you plan on using this, please make sure that you understand the process for calculating these values manually.

In order to use the calculator, you need to have a Java Runtime installed with a version of at least 25.0.5.

Java installations can be found here:
[Official from Oracle](https://www.oracle.com/java/technologies/downloads/)

[Adoptium Openjdk](https://adoptium.net/temurin/releases)
